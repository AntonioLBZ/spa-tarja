# Frontend

- TanStack Router (file-based; `src/routeTree.gen.ts` is generated by the Vite plugin and committed) and TanStack Query. API client: `hc<AppType>('/')` in `src/lib/api`.
- Imports in `src/`: `./` inside the same folder, otherwise `@/` (and `@server/` for types only), never `../`.
- **i18n** with `use-intl`, as in `spa-hoardex`. Messages live in `src/assets/locales/{en,es}.json`, English is the default and the source of the key types. The locale comes from the stored preference, then `navigator.languages`, then English, and it is not part of the URL. A test checks that every locale has exactly the same keys. No UI copy is hard-coded in components.
- **Mobile-first**: base CSS targets phones and widens with `@media (width >= 40rem)` and `(width >= 64rem)`. Touch targets are at least `--size-touch` (44 px), layouts honor `env(safe-area-inset-*)` (`viewport-fit=cover`), full-height blocks use `dvh`, and form controls inherit 16 px so iOS doesn't zoom on focus.
- Styles: plain CSS with variables and native nesting, no SCSS and no Tailwind (reversible if needed). Variables in `src/assets/styles/tokens.css`, BEM in the CSS of each route or component, Stylelint with alphabetical properties and no `!important`. Transitions always use the `--duration-*` and `--ease-*` tokens; `prefers-reduced-motion` zeroes them in a single place.
- Visual rules (colors, themes, shape, motion) live in [`DESIGN.md`](../../design-system/DESIGN.md).
- Shared components live in `src/components/<name>/` with their CSS and tests next to them: `Brand` (the logo), `UpdatePrompt` (the offer of a new version), `Notice`, `Toast`, `Button`, `Field`, `DateRangeFields`, `Card` and `CardList`, `Disclosure`, `ChoiceGroup` and `Icon`. Screens compose them instead of restyling raw elements (see [Components](../../design-system/DESIGN.md#components)).
- Shared components take their copy by props: they read no messages (`use-intl`), import no virtual module (`virtual:*`) and only `ButtonLink` knows the router. `Toast` reads the duration tokens through `lib/motion` and `DateRangeFields` the day check of `core/date`; both stay.
- `src/lib` never imports from `src/features` (ESLint enforces it), so the composition of the app around its pages lives in `src/providers.tsx`, used by `main.tsx` and by the tests.
