# Spacing

One scale of sizes, multiples of 0.25 rem, for every gap, padding and margin, plus the touch target and the height of the bars on the edges of the screen.

## Usage

An option of a `ChoiceGroup`:

```css
.choice-group__text {
    min-height: var(--size-touch);
    padding-block: var(--size-1);
    padding-inline: var(--size-4) var(--size-2);
}
```

A distance is always a `--size-*`, never a raw value. Layouts are mobile-first and widen at 40 and 64 rem; what is anchored to an edge pads by `env(safe-area-inset-*)`, and a height on the screen is in `dvh`, never `vh`.
