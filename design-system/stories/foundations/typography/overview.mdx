# Typography

Everything is set in IBM Plex Mono, amounts included, so the digits line up like a ledger. A person may choose IBM Plex Sans instead in Settings → Appearance: `data-typeface="sans"` on `<html>` swaps `--font-family` for it, turns the digits tabular (`--font-numeric`) so amounts still line up, and gives a word measured in characters more room (`--font-word-scale`). Monospace stays the default, and the look is drawn for it. The sizes are a minor third scale (×1.2) from a 1 rem base, and only the name of the app has a face of its own.

## Usage

The quiet line under a heading, the class `hint` of `base.css`:

```css
.hint {
    color: var(--color-content-secondary);
    font-size: var(--font-size-s);
    margin: 0;
}
```

The font comes from the page: a component never sets a family, and form controls take `font: inherit`, so they keep 16 px and iOS doesn't zoom on focus. A size is always a `--font-size-*`, never one outside the scale; hierarchy also uses the bold and case. Headings are set once in `base.css`, so a screen writes no size or margin for its titles, and a quiet line uses `hint` instead of a rule of its own.
