# CategorySelect

A `Select` of categories, each with its badge. All categories stays on top and the fallback, Other, follows it, so a new expense starts on it and a native list opens scrolled to the option chosen.

## Usage

The category of the add form, and the category filter of the list and of a group's ledger. It goes in a `Field`, like any `Select`; the options are the default categories and the person's own, named in the chosen language.
